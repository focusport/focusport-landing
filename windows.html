Focus modes

Allowlist mode or Blocklist mode

Allowlist mode keeps only the apps and websites you choose open and locks everything else on your PC. Blocklist mode does the opposite: you pick the distracting apps and websites to block, and the rest of Windows works as normal. Save your choices as a focus profile, such as Study or Work, and reuse it every session.

Schedules

Create a program with a start and end time, the days it runs, how many days it lasts and a category such as Study, Work, Write or Read. Programs sync with your phone, so a schedule you make on your PC shows up on Android too.

Why the Windows lock is hard to get around

Most PC blockers are one program you can close. FocusPort for Windows is built as several parts that watch each other, and it closes the usual escape routes while a session runs.

Task Manager is switched off

At session start, a system service sets the Windows policy that disables Task Manager, so Ctrl+Shift+Esc shows the standard "disabled by your administrator" message. If Task Manager is launched another way, it is closed again within a fraction of a second.

Settings and Control Panel are closed

Windows Settings and the classic Control Panel are closed on sight during a session, so Installed Apps and Programs and Features are not reachable for uninstalling mid-session.

No switching to another account

With Bulletproof mode on, Fast User Switching is hidden, so Win+L and Ctrl+Alt+Del cannot take you into a second Windows profile.

Parts that restart each other

A background service, a watchdog service, an agent in your desktop session and Task Scheduler recovery tasks. If one is stopped, the others bring it back.

Restarts do not reset the clock

The session state is saved to disk. After a reboot the service reloads it, works out the time left and puts the lock back before you reach your desktop.

Store apps are checked too

Microsoft Store apps run inside a shared frame process. FocusPort looks inside the frame to find the real app, so a Store game or social app cannot hide behind it.

In Allowlist mode everything is blocked except the tools you pick. If anything else holds the foreground for about 1.5 seconds, the focus screen returns. Taskbar clicks, file dialogs and the on-screen keyboard are recognised, so allowed work is not interrupted.

Windows app blocker FAQ

Is there a free app blocker for Windows?

Yes. FocusPort for Windows is free to download from the Microsoft Store and has no ads. Cross-device sync is free during beta.

Can FocusPort block websites on Windows?

Yes. A focus profile can include apps and websites, so you can keep only the sites you need open, or block the ones that distract you.

What is the difference between Allowlist mode and Blocklist mode?

In Allowlist mode only the apps and websites you choose stay open and everything else is locked. In Blocklist mode you pick the apps and websites to block, and the rest of Windows works as normal.

Can I close FocusPort from Task Manager during a session?

No. While a session is running, ending FocusPort from Task Manager is blocked, and so is uninstalling it.

What happens if I restart or shut down my PC during a session?

Restarting or shutting down your PC does not end your session.

What is Bulletproof mode?

Bulletproof mode is an optional strict setting. It turns off early stopping and switching accounts or Windows profiles while a session runs.

What makes FocusPort a strict blocker for Windows?

It removes the usual escape routes during a session: Task Manager is disabled by Windows policy, Settings and Control Panel are closed, Bulletproof mode blocks switching Windows profiles, several background parts restart each other, and the session resumes after a restart. Allowlist mode adds a rule that anything you did not allow stays blocked.

Can I uninstall FocusPort during a focus session?

Not easily. Windows Settings and the classic Control Panel are closed while a session is running, and the service keeps the app's files in use, so uninstalling mid-session is not practical. After the session ends you can remove it normally.

Is FocusPort an alternative to Freedom or Cold Turkey on Windows?

It is a free option aimed at the same job, with Allowlist and Blocklist modes, schedules and cross-device sessions with Android. Freedom and Cold Turkey are established tools with their own platforms and pricing, so compare what you need. Our comparison guide is at /blog/freedom-alternative-windows-android.html.

Does FocusPort for Windows sync with my phone?

Yes. Sessions, schedules and lists are shared with your Android phone, and a session you start on your PC also starts on your phone. Cross-device sync is in beta and free during beta.
